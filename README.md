# SmalBlu — Marketing Website

Production marketing site for [smalblu.ai](https://smalblu.ai): a dark, techno-futurist
single-page home + `/contact`, built with Next.js 15 (App Router), TypeScript,
Tailwind CSS v4, and Framer Motion. Fully static (`output: "export"`) — deploys to
Vercel out of the box, no server required.

## Develop

```bash
npm install
npm run dev        # http://localhost:3000
```

## Build

```bash
npm run build      # static export to ./out
```

## Deploy (Vercel)

Import the repo in Vercel — the Next.js preset picks up the static export
automatically. No environment variables needed.

## Brand

Colors and type come from the official branding card in `/assets`:

- Electric blue accent `#005EFF`, text-safe accents `#4096DB` / `#80B9E7`
- Near-black blue-tinted background `#04080F` (from the `#000F1A` brand family)
- Geist Sans/Mono (shipped via the `geist` package; the brand's Creato Display is
  not licensed for web embedding — swap in `app/layout.tsx` if a license is bought)
- Logo lockup + butterfly mark generated from the deck SVG exports by
  `scripts/prep-assets.mjs` → `components/logo.tsx`, `app/icon0.svg`
- Favicon PNG / apple icon / OG image generated by `scripts/make-images.ps1`

## Structure

- `app/page.tsx` — hero (animated console mock), cloud marquee, six-layers
  interactive, benefits bento, comparison, security, FAQ, final CTA
- `app/contact/page.tsx` — form (stub handler), Calendly embed, email/LinkedIn
- `components/` — one file per section; `reveal.tsx` and `counter.tsx` are the
  shared animation primitives (both respect `prefers-reduced-motion`)
- `app/sitemap.ts`, `app/robots.ts`, `app/manifest.ts`, `app/opengraph-image.png`
